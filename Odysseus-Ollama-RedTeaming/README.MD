# Offline Red Team AI Lab

**Fully local AI assistant for Red Teaming, Pentesting, and Security Research.**

This repository documents my offline AI setup using **PewDiePie's Odysseus + Ollama (Dolphin 3)** running on Docker. Everything stays 100% local on my laptop — no data is sent to the internet.

### Why This Setup?
- Privacy-focused (no data leaks)
- Used for generating red team scripts, payloads, automation, and evasion techniques
- Works completely offline
- Helps me build my Red Teaming Home Lab projects

### Hardware
- Laptop: RTX 4050
- OS: Windows 11
- Models: Dolphin-Llama3 (8B)

### Features
- Fully uncensored LLM for security research
- Code generation for Python, PowerShell, Bash
- Red teaming prompt engineering

## Quick Start

1. Install Docker Desktop
2. Run Ollama + Odysseus using `docker-compose`
3. Use custom system prompts optimized for red teaming
